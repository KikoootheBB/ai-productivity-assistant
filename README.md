# AI Productivity Assistant

A small multi-tool AI productivity application built with Python,
Streamlit and the OpenAI API.

## Features

- PDF Summarizer
- Email Generator
- Task Organizer
- Text Improver

## Architecture

The application separates the user interface, PDF processing,
AI communication and prompts into dedicated modules.

## Technologies

- Python
- Streamlit
- OpenAI API
- pypdf
- tiktoken
- python-dotenv
